# 2단계 검증

## 자동 검사
| 항목 | 결과 |
|---|---|
| 포맷(dart format, 140자) | 통과 |
| 린트(flutter analyze) | 문제 0개 |
| 전체 테스트(flutter test) | 58개 통과 |
| 리눅스 빌드(이 환경) | 성공(41MB) |
| 안드로이드·윈도우·맥 빌드 | GitHub Actions에서 모두 성공 |

## 안전 체크리스트
| 질문 | 답 | 근거 |
|---|---|---|
| 원본 파일을 수정·삭제하는 코드가 없는가 | 예 | 가져오기는 `readAsBytes`만 씀. 파일 쓰기/지우기는 앱 자기 폴더(로그·설정·사용자 폴더·키 대체 파일·임시 공유 파일)에만 있음 — 테스트 `안전 검사`가 코드 전체를 훑어 확인 |
| 대화 본문이 암호화 저장되는가 | 예 | AES-256-GCM. 테스트가 DB 원문에 본문 글자가 없는지 확인. 백업 파일도 비밀번호(PBKDF2)로 잠금 |
| 외부 AI로 보내는 범위가 사용자 설정을 따르는가 | 예 | 동의(범위 바꾸면 다시 동의) 없이는 AI 정리 불가. "제목만"일 때 본문이 요청에 없는지 테스트로 확인 |
| 키·토큰이 로그에 찍히지 않는가 | 예 | 로그는 키 모양 글자를 가리고, 본문이 들어갈 이름의 값은 버림 — 테스트로 확인 |
| 모든 문구가 한국어인가 | 예 | 화면 코드의 문구를 훑어 영어 낱말이 있으면 실패하는 테스트(상표 "챗GPT", "PDF", "AI", 라이선스 이름만 예외) |
| 글씨 크기 조절이 모든 화면에 적용되는가 | 예 | 앱 전체에 배율 적용. 15개 화면을 "아주 크게"로 그려 잘림 없음 확인 |
