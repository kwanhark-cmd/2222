## 안전 체크리스트
| 질문 | 답 | 근거 |
|---|---|---|
| 원본 파일을 수정·삭제하는 코드가 없는가 | 예 | 코드 전체 훑기 테스트. 새로 쓰는 파일은 앱 자기 폴더(사진 복사본·백업)와 업데이트용 임시 폴더·앱 실행 파일뿐 |
| 대화 본문이 암호화 저장되는가 | 예 | 변경 없음. 업데이트 전 백업도 같은 암호화 자료 파일 복사 |
| 외부로 보내는 범위가 설정을 따르는가 | 예 | AI는 동의한 범위만. 지메일은 읽기 전용, 본문 안 읽음. 업데이트 확인은 버전 정보만 받음 |
| 키·토큰이 로그에 찍히지 않는가 | 예 | 지메일 비밀번호·토큰은 보안 저장소에만, 로그 가림 규칙 유지 |
| 모든 문구가 한국어인가 | 예 | 문구 검사 테스트(지메일 안내의 "OAuth", "API", "ID", "JSON"은 구글 화면 이름 그대로라 예외) |
| 글씨 크기 조절이 모든 화면에 적용되는가 | 예 | 새 화면 포함 22개 화면 검사 |
| 앱 식별자를 바꾸지 않았는가 | 예 | 패키지 이름·번들 ID 그대로(안드로이드 런처 아이콘은 같은 앱 안의 별칭) |
