# 2단계 보고 — 주제별 자동 분류와 날짜별 타임라인

## 만든 것
- 무료 분류("검색만" 모드): 주제 사전 12개(앱 만들기, 유튜브·영상, 투자·재테크 등) + 사용자가 고친 낱말 기억
- AI 분류(선택): 클로드에 보낼 범위(제목만/일부/전체) 동의, 예상 비용(원화) 안내, 월 한도에서 자동 멈춤, 누적 비용 기록. 키 오류·잔액 부족·한도 초과·서버 바쁨·인터넷 없음을 구분해 안내
- 주제 관리: 이름 바꾸기(되돌리기), 하위 주제로 옮기기, 합치기(2단계 확인), 나누기(골라서 새 주제), 지우기. 한 대화가 여러 주제에 보임
- 사용자가 옮기거나 뺀 대화는 다시 정리해도 그대로, 이름 바꾼 주제도 계속 사용
- 타임라인: 연도 고르기, 이전/다음 달, 날짜별 묶음, 주제·AI 거르기
- 음성 명령: "이 대화를 ○○ 주제로 옮겨", "○○ 주제를 △△ 주제로 합쳐"(확인), "오늘 가져온 대화 정리해 줘", "메모 …", "읽어 줘", "그만", "이 대화 지워"(확인)

## 테스트 결과
- 분류·AI(가짜 서버) 테스트 9개, 음성 명령 테스트 통과. 실제 AI 호출은 하지 않음(비용 규칙)

## 못 한 것
- 실제 클로드 호출 확인(BLOCKERS 5번)
