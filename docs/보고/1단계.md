# 1단계 보고 — 통합 목록과 검색

## 만든 것
- 앱 뼈대: 첫 실행 안내(이름 → 글씨 크기 → 권한 → 내보내기 받는 법 → 샘플 체험), 여러 사용자(비밀번호 선택), 설정, 오류 처리, 기기 내 로그, 문제 신고
- 파일 넣기: 끌어다 놓기(컴퓨터), 파일 고르기, 안드로이드 "공유하기 → 이 앱"
- 파서 3종: 클로드(conversations.json), 챗GPT(conversations.json, 나뉜 파일 conversations-000.json…, chat.html), 제미나이(테이크아웃 JSON·HTML, 30분 단위로 대화 묶기). 압축 파일 그대로 읽음. 모르는 항목은 건너뜀
- 중복 없이 가져오기(대화 ID로 판단, 늘어난 대화는 갱신), 백그라운드 읽기 + 진행 막대 + 취소
- 저장: 기기 안 SQLite, 본문·메모 AES-256 암호화, 한글 본문 검색 색인(2글자 조각 + 1글자)
- 통합 목록(30개씩 나눠 불러오기), 검색창 하나(글자·음성), 정확히 일치/비슷한 말도 찾기, AI·별표·태그 거르기, 찾은 문장 미리보기·강조, 전체 보기, 읽어주기
- 원래 대화 링크(클로드·챗GPT), 제미나이는 날짜·제목만
- 대화별: 별표, 태그, 메모(글·말), 마크다운·글자·PDF로 내보내기, 앱에서 지우기(2단계 확인)

## 테스트 결과
- 파서 테스트 8개, 저장·검색 테스트 16개 통과(샘플 3종, 깨진 파일, 나뉜 파일 압축, 한글 날짜, 취소, 중복)
- 실제 리눅스 앱을 가상 화면에서 실행해 확인(화면 사진: `docs/보고/화면/`)
