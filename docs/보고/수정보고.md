# 수정 보고 — 1.1.0

## 바뀐 것
1. **업데이트 방식**
   - 설정 맨 위 "업데이트 확인" → 새 버전 알림 → "업데이트"를 누르면 자료 자동 백업 → 내려받기 → 설치(맥: 앱 교체 후 다시 열기 / 윈도우·리눅스: 앱 닫힘 → 덮어쓰기 → 다시 열기 / 안드로이드: 설치 화면). 자동으로 내려받지 않음
   - **1.1.1에서 바뀜**: 서명 키 없이 배포하므로 안드로이드는 기존 앱 위에 설치가 안 돼요. 안드로이드는 앱 안 설치를 없애고 "백업 파일 만들기(앱 밖) → 내려받기 화면 → 기존 앱 지우기 → 설치 → 백업에서 되살리기" 안내로, 맥은 내려받기 화면 안내로 바꿈. 윈도우·리눅스는 그대로
   - 하루 한 번 조용히 확인 → 홈과 설정 탭에 "새 버전 있어요"
   - GitHub Actions가 main에 새 버전이 올라오면 Releases에 버전 태그와 한국어 변경 내역(CHANGELOG.md)으로 배포
   - 자료(설정·대화·주제·별표·태그·메모)는 사용자 폴더, 열쇠는 보안 저장소 → 앱 파일을 덮어써도 유지. 자료 버전 2→3 자동 변환, 변환 전 백업, 기존 사용자는 첫 안내 건너뜀
2. **오류 대비**: 실패 창마다 "다시 시도"와 "문제 신고", 사라진 화면으로 대화상자를 띄워 앱이 멈추던 문제를 앱 전체에서 차단, 스크롤 위치 유지, 실패 단계 기록, 상태 3가지 따로 표시, 샘플 자동 숨김, 파일 불러오기 버튼, 만료 링크·빈 파일 안내
3. **화면 재설계**: 큰 검색창이 주인공, 크기로 중요도, 채운 카드와 그림자, 주제 색, AI 배지 색, 형광펜·큰 숫자, 탭 메뉴(휴대폰 아래·컴퓨터 왼쪽), 넓은 화면 목록+본문(주제는 3칸), 설정 묶음 카드와 맨 아래 빨강 위험 카드
4. **이 앱 전용**: 지메일 실제 연결(단계별 도우미·JSON 불러오기·안내 메일 알림), 앱 꾸미기(이름·아이콘·색 테마, 안드로이드 홈 화면 아이콘), 대화 화면 "원본으로 가기"와 마크다운·PDF·텍스트 버튼, 한국어 제미나이 테이크아웃 대응·파서 보강

## 업데이트 방법(사용자) — 1.1.1부터
- 내려받는 곳: 공개 Releases 화면 https://github.com/kwanhark-cmd/2222/releases/latest (로그인 필요 없음)
- **안드로이드(꼭 백업부터)**: 설정 → 자료 관리 → 백업 파일 만들기(앱 밖 "다운로드" 폴더 등에 저장) → 새 `…-android.apk` 받기 → 기존 앱 지우기 → 설치 → 첫 안내 마지막 단계(또는 설정 → 자료 관리)에서 백업에서 되살리기. 앱을 지우면 앱 안 자료가 지워지므로 백업이 언제나 먼저예요
- **컴퓨터**: 새 파일을 받아 기존 앱과 바꿔 넣기(윈도우·리눅스는 앱 안 "업데이트"로도 가능). 자료는 사용자 폴더에 있어 그대로 남아요
- 1.0.0을 쓰던 분이 1.1.0을 처음 열면 자료가 자동으로 바뀌고(변환 전 백업), 첫 안내 없이 바로 홈이 나와요
