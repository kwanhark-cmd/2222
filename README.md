# AI 대화 기록 정리 비서

클로드, 챗GPT, 제미나이와 나눈 대화를 **한곳에 모아** 주제별·날짜별로 정리하고, **검색창 하나로** 찾는 앱입니다.
대화 내용은 내 기기 안에만 암호로 잠가 저장하고, 인터넷이 없어도 검색할 수 있어요.

## 1. 설치하기

설치 파일은 공개 **Releases** 화면에 있어요. 로그인 없이 누구나 받을 수 있어요.

**https://github.com/kwanhark-cmd/2222/releases/latest**

화면 아래 **Assets** 에서 내 기기에 맞는 파일을 받습니다(`1.1.1` 자리에는 그때의 버전 번호가 들어가요).

| 기기 | 받을 파일 | 설치 방법 |
|---|---|---|
| 안드로이드 | `ai-chat-organizer-v1.1.1-android.apk` | 휴대폰에서 받은 파일을 누르기. "출처를 알 수 없는 앱 설치"를 허용해야 해요 |
| 윈도우 | `ai-chat-organizer-v1.1.1-windows.zip` | 압축을 풀고 `ai_chat_organizer.exe` 실행. "Windows의 PC 보호" 창이 나오면 **추가 정보 → 실행** |
| 맥 | `ai-chat-organizer-v1.1.1-macos.zip` | 압축을 풀고 앱을 "응용 프로그램"으로 옮긴 뒤 열기. 막히면 **시스템 설정 → 개인정보 보호 및 보안** 맨 아래에서 **"그래도 열기"** (맥 14 이하는 오른쪽 클릭 → 열기). 아직 애플 서명이 없어서 그래요 |
| 리눅스 | `ai-chat-organizer-v1.1.1-linux.zip` | 압축을 풀고 `ai_chat_organizer` 실행 |

> 아이폰은 아직 지원하지 않아요(준비 중).
>
> 이 앱은 서명 키 없이 배포해요. 그래서 안드로이드는 새 버전을 기존 앱 위에 설치할 수 없고, 아래 순서로 바꿔요.

### 안드로이드 새 버전으로 바꾸기(꼭 백업부터)

안드로이드에서 앱을 지우면 **앱 안의 대화·주제·메모·설정도 함께 지워져요.** 그래서 꼭 이 순서대로 해 주세요.

1. **백업 파일 만들기**: 지금 쓰는 앱의 **설정 → 자료 관리 → 백업 파일 만들기**. 비밀번호를 정하고, 저장할 곳은 **"다운로드" 폴더처럼 앱 밖**으로 고르세요.
2. **새 파일 받기**: 위 Releases 화면에서 `…-android.apk` 받기 (앱의 **설정 → 업데이트 확인 → 내려받기 화면 열기**로도 열려요).
3. **기존 앱을 지워요.** (1번의 백업 파일이 휴대폰에 있는지 먼저 확인하세요)
4. **설치**: 받은 파일을 눌러 설치.
5. **되살리기**: 새 앱을 열고 이름을 넣은 뒤, 첫 안내 마지막 단계(또는 **설정 → 자료 관리**)의 **백업에서 되살리기**로 백업 파일을 고르고 비밀번호 입력.
   AI 연결 키는 백업에 들어가지 않으니 썼다면 다시 넣어 주세요.

> 1.1.0의 업데이트 창에 나오는 "업데이트" 버튼은 안드로이드에서는 설치되지 않아요. "아니요, 그만둘게요"를 누르고 위 순서대로 해 주세요.

### 컴퓨터(윈도우·맥·리눅스) 새 버전으로 바꾸기

- 새 파일을 받아 압축을 풀고, **기존 앱(폴더)과 바꿔 넣으면** 돼요. 맥은 "응용 프로그램" 폴더의 기존 앱과 바꿔 넣기.
- 윈도우·리눅스는 앱의 **설정 → 업데이트 확인 → 업데이트**로도 바꿀 수 있어요(먼저 자료를 자동으로 백업해요).
- 자료는 앱 파일이 아니라 사용자 폴더(맥: 응용 프로그램 지원 폴더, 윈도우: AppData, 리눅스: ~/.local/share)와 보안 저장소에 따로 있어서 **앱을 바꿔도 그대로 남아요.** 사용자 폴더를 지우지 않는 한 유지돼요.

## 2. 각 AI에서 대화 기록 받기("내보내기")

내보내기 요청은 각 AI 설정에서 **직접** 눌러야 해요. 메일로 링크가 오면 파일을 받으세요. 앱 안의 **대화 넣기 → 각 AI에서 파일 받는 법**에도 같은 안내와 바로가기가 있어요.

### 클로드
- 어디서: 클로드 웹사이트 또는 컴퓨터용 앱 (휴대폰 앱에서는 안 돼요)
- 왼쪽 아래 **내 이름 → 설정 → 개인정보 보호 → 데이터 내보내기**
- 메일로 온 링크는 **24시간 안에** 눌러서 받으세요.

### 챗GPT
- **프로필 그림 → 설정 → 데이터 제어 → 데이터 내보내기 → 내보내기 확인**
- 메일로 온 링크는 **24시간 안에** 눌러서 받으세요.

### 제미나이
- 구글 테이크아웃(takeout.google.com) 에서 **모두 선택 해제 → "내 활동"만 선택 → "모든 활동 데이터 포함됨"을 눌러 "제미나이 앱"만 선택 → 다음 단계 → 내보내기 만들기**
- 메일 링크는 약 7일 동안 쓸 수 있어요.
- 제미나이 기록은 일부만 담길 수 있어요(첨부 그림, 지운 기록 등은 빠질 수 있음).

## 3. 앱에 파일 넣기

받은 **압축 파일(.zip)을 풀지 말고 그대로** 넣으면 됩니다.

- **컴퓨터**: 앱의 **대화 넣기** 화면에 파일을 끌어다 놓거나 **파일 고르기**를 누르세요.
- **안드로이드**: 파일 앱이나 메일에서 파일을 **공유하기 → AI 대화 정리 비서**로 보내거나, 앱에서 **파일 고르기**를 누르세요.

같은 파일을 다시 넣어도 겹치지 않고 새 대화만 더해져요. 원본 파일은 읽기만 하고 절대 바꾸거나 지우지 않아요.

## 4. 주요 기능

- **홈**: 맨 위 큰 검색창(말로도), 오늘 할 일, 색깔 있는 주제 타일, 최근 대화, 큰 숫자 통계. 아래(휴대폰)·왼쪽(컴퓨터) 메뉴로 홈·찾기·주제·날짜·설정 이동
- **대화 찾기**: 세 AI의 제목과 내용 전체를 한 번에 검색. "지난달 유튜브 앱"처럼 말이나 글로, 정확히 일치·비슷한 말도 찾기, 찾은 낱말 형광펜. 컴퓨터에서는 목록과 내용을 나란히
- **주제별 보기**: 자동으로 주제(폴더)를 나눔. 주제마다 색, 이름 바꾸기·옮기기·합치기·나누기·하위 주제. 고친 내용은 다음 정리 때 기억
- **날짜별 보기**: 연·월로 이동하는 타임라인
- **정한 내용**: 주제별로 "지금까지 정한 내용"을 모아 보여주고 읽어 줌
- **대화 보기**: 요약, 별표, 태그, 메모(말로도), 읽어주기, 원본으로 가기, 마크다운·PDF·텍스트로 내보내기, 관련된 지난 대화
- **음성**: 말로 검색·명령("앱 만들기 주제로 옮겨", "오늘 가져온 대화 정리해 줘"), 읽어주기(속도 조절). 마이크가 없는 기기는 글자 입력칸
- **지메일 연결(선택)**: 내보내기 안내 메일이 오면 "내려받을 때가 됐어요"(설정 > 지메일 > 구글 연결 준비하기)
- **앱 꾸미기**: 표시 이름, 아이콘(안드로이드는 홈 화면 아이콘까지), 색 테마
- **편의**: 글씨 크기 3단계, 밝게·어둡게·고대비, 움직임 줄이기, 여러 사용자(비밀번호), 비밀번호로 잠근 백업·되살리기
- **상태 표시**: 홈과 설정에 "가져온 대화 수 / AI 연결 / 지메일 연결"을 따로 보여줘요

## 5. AI로 더 똑똑하게 정리하기(선택, 비용 있음)

기본은 비용이 없는 "검색만" 모드예요(낱말 기준 자동 정리). 클로드 연결 키가 있다면:

1. **설정 → AI 연결**에서 "클로드로 정리"를 고르고 **연결 키 넣기**
2. **AI로 보낼 범위**(제목만 / 일부 / 전체)를 고르고 동의 켜기
3. **한 달 비용 한도**를 정하기 (넘으면 자동으로 멈춰요)
4. **주제별 보기 → 다시 정리하기 → AI로 정리**: 보내기 전에 예상 비용을 원화로 보여드려요

## 6. 문제가 생기면

**설정 맨 위의 문제 신고**(또는 실패 창 안의 문제 신고 버튼)에서 신고 파일을 저장하거나 복사해서 보내 주세요. 대화 내용과 키는 담기지 않아요.
